# Installation Configuration Preview

## Purpose

The installation preview describes proposed agent installation
artifacts without changing the host.

It is a planning component, not an installation executor.

## Agent preview

    .venv/bin/python installer/installation-preview.py \
      --role agent \
      --server https://patch.example.test \
      --ca-cert /path/to/ca.pem

## Test certificate option

    .venv/bin/python installer/installation-preview.py \
      --role agent \
      --server https://patch.example.test \
      --certificate-mode generate-test-ca

This selects a proposed certificate mode only.

No certificate is generated by the preview command.

## JSON manifest

Add:

    --format json

The manifest contains:

- Schema version
- Installation role and target type
- Proposed filesystem artifacts
- Portable agent configuration
- Certificate source or proposed generation mode
- Proposed installation phases
- Explicit safety policy

## Current limitations

The preview does not yet verify certificate file contents,
validate installation target ownership, execute staging,
generate certificates, activate services, or enroll agents.

Those operations require integration with the existing
security-checked installer components.

Server installation remains unimplemented.

## Safety

Production installation, live host mutation, enrollment,
service activation, and network requests remain disabled.

No private keys, credentials, or enrollment tokens are
included in the manifest.
